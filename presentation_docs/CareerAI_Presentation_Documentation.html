CareerAI Presentation Documentation

CareerAI analyzes a resume PDF, predicts the most suitable job role, compares jobs semantically, calculates an explainable ATS score, and recommends role-specific improvements and projects.

1. Project Objective

The goal of CareerAI is to help a job seeker understand how strong their resume is for a target role. The system gives a predicted role, detects skills, finds missing role skills, compares job descriptions, calculates an ATS score, and suggests real portfolio projects.

4. Model Performance Comparison

The app now trains and compares two classic text-classification models using the same train/test split: Logistic Regression and Naive Bayes.

ModelStrengthWeaknessWhy compare it?
Logistic Regression Strong baseline for sparse TF-IDF text features. Can be slower than Naive Bayes on very large data. Often performs well for resume/job text classification.
Naive Bayes Fast and simple probabilistic text classifier. Assumes word independence, which is not always true. Useful baseline to compare speed and accuracy.
Presentation line: "Both models are trained on the same cleaned resume text and TF-IDF vectors. We compare accuracy, precision, recall, F1 score, and confusion matrix to select the better model."

5. ATS Score Definition

ATS Score = Keyword Match x 40% + Skill Coverage x 30% + Formatting Rules x 30%
Keyword Match - 40%

Counts action words and ATS-friendly keywords such as built, managed, implemented, improved, and optimized.

Skill Coverage - 30%

Checks how many technical skills are detected in the resume, such as Python, SQL, Excel, machine learning, or cloud tools.

Formatting Rules - 30%

Checks contact details, LinkedIn/GitHub, resume length, sections, bullets, and certification signals.

This score is transparent because each component shows evidence and contribution. The user can see exactly why they got the score and how to improve it.
